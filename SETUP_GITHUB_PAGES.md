# How to Enable GitHub Pages

Follow these steps to publish this repository as a live demo:

1. Go to **Settings** in your repository.
2. Scroll down to **Pages**.
3. Under **Source**, select the branch (`main`) and folder (`/root`).
4. Click **Save**.
5. GitHub will generate a link like:
   `https://veri-ai.github.io/web-localization-demo`

## Why This Matters
- **Code View** → Developers can read and reuse the source files.
- **Page View (Live Demo)** → Non-technical viewers can interact with the project directly.
